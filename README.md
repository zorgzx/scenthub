# ScentHub

Fragrance Catalog and Review Community. Final Exam Project (Java Spring Boot).

## About
ScentHub is a web application where perfume lovers discover fragrances, read reviews, rate perfumes by longevity, sillage and overall impression, and keep personal lists (Favorites, Want to try). The app shows average ratings and a monthly top of the best-rated perfumes. Moderators approve reviews, and the admin manages the catalog.

## Architecture
Frontend -> Controller -> Service -> Repository -> Database (PostgreSQL)
